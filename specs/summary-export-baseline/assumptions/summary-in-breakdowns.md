# Summary is a section at the top of Breakdowns, not its own page

**Context:** The issue allows either a section in Breakdowns or a new page.

**Decision:** A Summary section, open by default, sits above the existing sections. The report reuses the same widget and gets a sidebar link.

**Alternatives:** A new Summary page with its own nav entry.

**Impact:** No new nav item, the filter bar is reused, and one widget serves both the dashboard and the report.

**How to reverse:** Move the widget into a new page module and add a nav entry.
